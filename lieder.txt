# ============================================================
# Liederdatei für die Xylophon-App
# ============================================================
# Zeilen mit # am Anfang sind Kommentare. Die App liest sie nicht.
#
# Kategorie: Name      neue Kategorie (gilt für alle folgenden Lieder)
# Lied: Titel          neues Lied
# Info: Text           kurzer Text unter dem Titel
# Quelle: Text         Hinweis zu den Strophen (optional)
#
# Töne: ...            eine Notenzeile. Jeder Ton ist ein Notenname oder eine Balkennummer:
#   C D E F G A H C'   (C = tiefes C = Balken 1 ... C' = hohes C = Balken 8)
#   1 2 3 4 5 6 7 8    (gleich, als Nummer)
#   G      = Ton G (Balken 5), 1 Schlag lang
#   G:2    = Ton G, 2 Schläge lang (auch 0.5, 1.5, 3, 4 ...)
#   G*     = Ton G mit gestricheltem Ring (Ton eigentlich eine Oktave tiefer)
#   -      = kurze Pause (1 Schlag), -:0.5 = halber Schlag
#   Statt Zahlen gehen auch Farben: rot orange gelb grün dunkelblau hellblau violett pink
# Text: ...            die Silben zu dieser Notenzeile, eine Silbe pro Ton (Pausen zählen nicht)
#   Al- le     = Silben eines Wortes, mit Bindestrich
#   –          = (Gedankenstrich) Silbe über diesen Ton weiter halten
#   _          = Ton ohne Silbe
#
# Strophe 2:           ab hier kommt der Text der 2. Strophe
#   Text: ...          Silben für die nächste Notenzeile (gehaltene Töne – zählen nicht mit)
#   =                  diese Notenzeile hat denselben Text wie Strophe 1
#   Zeile: ...         ganzer Text für diese Notenzeile, ohne Silben-Zuordnung
#   Ganz: ...          ganze Strophe als freier Text (eine Zeile pro Ganz:)
#   Passt die Silbenzahl einer Text:-Zeile nicht, zeigt die App sie als ganze Zeile.
#
# Beispiel:
#   Lied: Mein Lied
#   Info: Von mir.
#   Töne: C D E F G:2 G:2
#   Text: Al- le mei- ne Ent- chen
#   Strophe 2:
#   Text: Al- le mei- ne Gäns- chen
# ============================================================
